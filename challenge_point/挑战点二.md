# 挑战点二：应用AD设计STM32硬件原理图

## 一、创建PCB项目文件以及AD汉化
1、**创建项目**：打开AD，点击File->New->Project，选择Project_name以及项目地址然后创建该项目
2、**创建PCB、原理图文件**：点击File->New->Schematic创建原理图文件、点击File->New->PCB创建PCB文件，然后点击最左上方的按钮 / ctrl + s保存文件
3、**创建PCB、原理图库文件**：点击File->New->Library，弹出窗口左侧栏选择File，右侧选择Schematic Library创建原理图库文件、选择PCB Library创建PCB库文件，点击Create创建文件，点击最左上方的按钮 / ctrl + s保存文件
4、**AD汉化**：右键选择Perferences，在弹出的页面中选择System->General，勾选Use localized resources，点击Apply、OK，然后重启Altium即可

## 二、原理图库的绘制
### （一）、绘制原理图库元器件
#### 1、概念说明
* 原理图符号：元件在原理图上的表现形式，主要由元件边框、管脚（包括管脚序号和管脚名称）、元件名称及元件说明组成，通过放置的管脚来建立电气连接关系

#### 2、原理图元件绘制
1、打开原理图库文件，右下角Panels选择SCH Library，左侧栏变为原理图元件库
2、左侧栏点击Add输入元件名称添加新元件
3、绘制元件时可在右侧Properties栏修改元件、管脚、图形元素相关属性
4、点击Add Footprint填写名称后点击确定以添加封装

>注意：
1、快捷键vgs / View->Grids->Set Snap Grid修改格点大小，约定管脚放置格点100mil，图形元素格点10mil
2、对于多Part元件，选中元件后点击Tools->New Part即可生成新Part

### （二）、学习调用他人的原理图库
#### 1、根据原理图生成原理图库
1、选中原理图
2、点击Design->Make Schematic Library
3、在弹出页面取消所有勾选后点击确定
4、ctrl + c、ctrl + v将需要的元件添加至自己的原理图库

#### 2、获取AD的官方库
1、打开网页 https://www.altium.com/documentation/other_installers ，登录AltiumLive账号后下拉页面找到**Altium Designer 23.2 Libraries**，点它的 **Download Libraries**，下载完成之后解压缩
2、将解压缩得到的库文件移动到Altium->ADAgile->Library中（可选）
3、打开AD界面，右侧点击Components，点击三条横杠的按钮，选择Libraries Preferences
4、在打开的页面上侧选择installed栏，下侧点击Install…
5、找到库文件所在的地址，选择Miscellaneous Connectors.IntLib和Miscellaneous Connectors.IntLib，点击打开
6、看到页面中出现了这两个库且无错误信息代表库文件添加成功，点击close即可，之后可以在Components栏三条横杠左侧选择要使用的库文件

#### 3、从立创商城中下载元器件
1、在立创商城界面搜索栏搜索需要的元器件然后点击数据手册
2、点击右下角的立即点开
3、点击文件->导出->AD，得到一个解压包
4、在解压包中点点点文件夹找到一个(.schdoc)后缀的文件，双击打开它
5、使用CV大法将该元器件复制到自己的原理图库中

### （三）、检查原理图库的正确性并生成报告
1、打开原理图库
2、点击Reports->Component Rule Check，在弹出窗口选择所有选项
3、点击OK生成报告

## 三、原理图的绘制
> 注意：绘制原理图时的格点应该设置为100mil
### （一）、原理图页的大小设置
1、点击Properties / 双击图纸页边缘唤出Properties栏
2、右侧栏中的Page Options选择Standard可选择标准页大小（A4、A3等），选择Custom自定义高度和宽度

### （二）、原理图库的调用及器件的摆放
* **库的调用**：Panels选择Components将Components移至右侧栏，选择自己需要的库，在库中选择元件，然后直接拖动则可以摆放元件、双击可摆放多个该元件
* **旋转元件**：选中该元件后按空格键
* **镜像**：拖动元件状态下按X可实现左右镜像，按Y可实现上下镜像
* **元件对齐**：框选需要对齐的元件，按A，选择对齐方式

### （三）、绘制器件导线及导线的属性设置
* **走线**：快捷工具栏点击两条蓝色折线按钮进入走线，右键 / esc退出走线
* **GND / 电源选择**：快捷工具栏点击GND按钮添加VCC、GND图标（可视为一种特殊的网络标号）
* **导线属性设置**：选中导线后双击可设置导线的宽度、颜色等属性
* **网络标号**：点击Place->Net Label后可放置网络标号，网络标号可简化连接网络，具有相同网络标号的导线相互连接 
  
### （四）、非电气对象（辅助线、文字）放置
* **辅助线放置**：快捷工具栏点击绘图按钮放置辅助线，辅助线可用于在原理图中分隔不同部分
* **文字放置**：快捷工具栏点击**A**按钮选择Text String放置文字，文字可用于原理图的说明

### （五）、元器件的位号编号排序
1、点击Tools->Annotation->Annotate Schematics / 快捷键TAA进入元器件位号编号排序对话框
2、点击**Reset All**使全部位号重置问号
3、点击**Update Changes List**预览生成新编号，新编号出现在Proposed栏
4、点击**Accept Changes->Execute Changes**对元器件的位号按照Proposed栏进行编号排序

> 元器件复制 / 剪切时位号不变的设置：点击Perferences->Schematic->Graphical Editing，取消勾选Reset Parts Designators On Paste，点击Apply->OK。之后复制元器件时位号自动递增，递增量可在Perferences->Schematic->General的Auto-Increment During Placement处的Primary处设置

### （六）、快速查找元器件
* **查找文本跳转**：点击快捷键ctrl + F弹出查找文本跳转窗口，输入查找文本并设置查找选项后点击OK即可跳转至查找文本
* **快捷键跳转**：点击快捷键J可选择跳转方式。点击JC然后输入要跳转的器件名点击OK可跳转到该器件

### （七）、原理图常见错误的编译和检查
#### 1、常见错误
* **Duplicate Part Designators**:存在重复元件位号
* **Floating Net Labels**:存在悬浮的网络标号
* **Floating Power Objects**:存在悬浮的电源端口
* **Nets with only one pin**:存在单端网络

> 建议：右键工程（.PrjPcb文件）选择Project Options，在Error Reporting栏将以上四种错误的Report Mode修改为Fatal Error（致命错误），对于其他必须杜绝的错误也可执行以上操作

#### 2、错误的编译与检查 
  右键工程（.PrjPcb文件）选择第一项Validate PCB Project，在弹出的 Messages 窗口 / Panels->Messages会报出检查到的错误，双击错误项可跳转至错误发生处

## 四、原理图设计的其他相关操作
#### 1、BOM物料表的导出
  点击Reports->Bill of Materials，在弹出窗口的左侧栏会出现原理图中元器件的相关信息；右侧栏选择Columns可选择左侧栏中显示的信息种类，选择General后可在File Format处选择导出的BOM物料表的文件格式、在Template处选择导出文件使用的模板。选择好导出文件相关选项后点击Export即可导出BOM物料表的文件

#### 2、原理图的PDF打印输出
  点击File->Smart PDF后在弹出窗口配置相关选项后即可导出项目 / 原理图的PDF文件
